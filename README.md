# LifeAtlas · 生活全图

一个可在 Windows 本地持续记录、阅读和思考的个人空间。核心资料保存在自己的电脑，不需要打开 Codex，也不要求登录云端账户。

[下载最新版本](https://github.com/hjfieohj/lifeatlas/releases/latest) · [安装与升级](docs/DOWNLOADS.md) · [本地功能与连接指南](docs/LOCAL-WORKSPACE.md)

## 可以做什么

- **今日**：查看自己的待办和最近更新的投资、生活记录。
- **个人成长 / 环境感知**：建立主题，记录经历、观察、反馈、理解与行动；整理五层环境，保存修改历史。
- **知识宇宙**：三维星云交互；股市、心理学、哲学、天文学、数学、物理、政治与资本七个领域。可自建星云、上传本地知识库、写笔记、收藏和建立联系。
- **投资研究、人生丰富度、任务记录**：新增、编辑、查找、分类、分批加载、JSON 导出和回收站恢复。投资是研究日志，不提供实时行情或自动交易。
- **原位 AI 辅助**：空白时帮助开始，已有内容时总结扩展。发送前预览当前问题与引用；结果附在原处，不自动改写原文。支持自己的 API 或事先准备的本机模型。
- **邮箱**：Gmail、163、QQ 各一个连接，只读同步标题，打开后缓存文本正文；缓存可离线阅读。
- **本地备份**：完整备份与恢复，保留记录、知识库、邮件缓存和分析。连接密钥单独加密存放，不进入资料备份。

提供 **深空 · 暗色** 与 **晴空 · 亮色** 两套皮肤，可关闭动态背景。知识宇宙三维视口保留深空，阅读和工具随皮肤切换。

## Windows 使用

下载 `LifeAtlas-Windows-x64.zip`，解压后双击 `LifeAtlas.exe`。运行 `Install-Desktop-Shortcut.cmd` 可创建桌面与开始菜单入口。程序附带运行时和字体，无需安装开发工具。

升级先保留完整备份，停止旧服务，仅替换程序文件，保留旁边的 `LifeAtlas本地资料`。详细步骤见[下载说明](docs/DOWNLOADS.md)。

远程 AI、外部资料链接和邮箱同步需要网络；记录、已有知识库和邮件缓存可以离线使用。本机模型需要事先准备。所有联网请求由用户主动发起。

## v0.4.0 日常使用优化（历史）

本地发布入口与早期原型分离，发布包不再加载演示邮件、模拟归档、情景切换、原型设置或闲置的顶层弹窗。构建检查会拒绝这些控制器重新进入本地入口。

补充记录查找、回收站、连接配置离开提醒、自动回看 AI 结果与较早分析翻页；修正成长资料保存位置的说明和快速切换邮件时的响应顺序。连续输入合并写入，内部草稿恢复快照设容量边界，正式成长修改历史和 AI 结果不受该边界影响。

早期托管原型与相关历史文档仍保留为源码历史参考，不是当前本地发布或默认开发入口；它们的演示流程不会出现在 Windows 程序中。

## 开发

使用 Node.js 24.13.0。默认开发入口运行完整本地功能，默认端口 `5174`，资料位于被 Git 忽略的 `.local-data`，与安装版分开。

```powershell
npm ci
npm run dev
```

打开终端显示的本机地址。源码修改后重新运行。指定端口使用 `npm run dev -- --port 5180`。

```powershell
npm run typecheck
npm test
npm run build
```

构建产物位于 `dist-local`。Windows 发布打包附带 Node 24.13.0 运行时、原生桌面入口、许可与使用说明。发布脚本只接受已提交源码并检查个人文件排除情况。

本地入口为 `local/application.ts` 与 `local/entry.ts`；SQLite 服务为 `local/server.mjs`，连接与文件功能为 `local/integrations.mjs`。验证范围见[本地使用检查](docs/DAILY-USE.md)。

## 资料边界

个人数据库、邮件缓存、上传原件、导出文件、备份、API Key 和邮箱授权码只留在用户电脑，不属于公开仓库或下载包。自动测试和协议模拟仅用于验证实现，不会给新安装填充虚构个人记录，也不自动调用付费服务。
