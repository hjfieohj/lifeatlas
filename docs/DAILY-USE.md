# 本地日常使用检查 · v0.6.0

## 正式入口

Windows 程序和默认 `npm run dev` 使用同一套本地界面及 SQLite 接口。`local/application.ts` 只装配真实模块，不初始化虚构邮件，不绑定模拟归档、模拟失败或原型重置处理器。本地服务只提供当前成长与本地连接接口，早期托管 Gmail OAuth 路由不进入该服务。

桌面程序保留独立窗口，图标更新为原创极光星云；按钮、导航和面板采用苹果风格，背景保留星空与蓝天白云。导航包含今日、个人成长 / 环境感知、知识宇宙、投资研究、人生丰富度、邮箱、任务记录、偏好设置；投资与人生可按用户偏好隐藏。AI 始终在内容后面，不占导航。

## 玻璃与基本环境

在「偏好设置 → 外观与动态 → 玻璃质感」调节所有模块面板及知识阅读区：透明度 0–65%（默认 36%）、磨砂强度 0–40px（默认 20px）。滑块显示数值、支持键盘，即时预览且自动保存；恢复默认只重置玻璃，保留皮肤与动态。透明度只影响面板，不淡化文字或输入框。窗口及知识 iframe 同步保留当前输入、笔记和三维图谱。系统减少透明效果时强制实心并说明原因，仍保留已存选择；不支持模糊时使用近实心回退。

成长页的「基本环境」在没有主题时也显示个人、家庭、周围社会、地区文化（民间与政府）、国家与国际五个入口。选择一个即展开相应表单；第一次点击不产生数据库记录，点击保存才创建默认名“我的基本环境”的主题，保存前可以改名。已有主题编辑该主题的环境与历史，不是共用全局个人档案。打开表单后切换五层会保留输入。

地区内容分民间生活与文化、政府与公共治理；国家制度与公共政策可填写适用范围、生效时间、来源、实际影响与待核实信息。旧五层 ID、环境 JSON、修订和 AI 来源关联继续保留；不预填个人样例或政策结论。

## 内容与保存

新安装不添加个人示例主题或虚构记录。此前 v0.4 的本机升级已备份并清理用户明确标注的旧样例；本次外观升级不清理资料。公开包不包含本机资料，普通其他用户升级不根据标题猜测或自动删除任何主题。

成长经历手动提交保存并保留修改历史。投资、生活、待办的填写草稿自动留存，点击保存后进入记录；查找和分批加载不替换正在编辑的输入框。移到回收站可恢复同一记录及关联分析。清空回收站会删除原记录，界面确认明确说明对应的 AI 分析继续保留在本机。

连续输入在短暂停顿后合并写入；浏览器恢复日志仍即时记录。显式备份先等待当前输入同步。冲突不覆盖另一窗口的数据，而是保留草稿并要求重新读取。

内部 `local_state_history` 是草稿恢复检查点，不是成长修改历史：每个存储项目最多每分钟留一个旧状态，保留最近最多 16 份、合计最多 12MB。已有正式内容、成长修订和 AI 分析不按此策略删除；启动生成的完整备份也不按该策略清理。状态容量按 UTF-8 字节校验，避免中文内容在提交时超出接口大小。

## AI 与连接

结果附在所属输入或记录下方，重新打开时按可见内容从本机恢复最近结果；历次分析可分批继续回看。待处理请求、完成和失败状态在同一页面的保存 / 重建后接续。用户修改原文会看到旧分析依据变化的提示。

只有点击发送才请求配置的模型。预览绑定当时的服务地址和模型，配置被其他窗口改变时先阻止发送并要求重新预览。原始输入、引用、结果、模型、服务地址、所属内容与时间保存到本机。

AI 与邮箱配置不进入填写草稿自动保存。未保存离开时有提醒。未连接邮箱时同步不可用，缓存仍可阅读。快速选择不同邮件时仅最后一次选择更新阅读区。

## 当前能力边界

AI 接入为兼容 chat/completions 的文字接口，没有自主操作电脑、交易或邮件的工具。邮箱为只读 IMAP；投资为研究记录。文件支持及容量、备份与连接密钥说明见[连接指南](LOCAL-WORKSPACE.md)。这些边界在界面中明确，不以虚构成功状态替代未完成的连接。
