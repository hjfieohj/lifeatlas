# 可选主模块与人生丰富度

2026-10-31 用户要求：投资与人生丰富度分别在皮肤设置附近提供开关；开启才在主导航显示，关闭隐藏；新板块标题下固定显示“人的创造性是本质的，人的社会化是必然的。”

## 本轮行为

偏好设置 → 外观与动态 → 选择主模块。两项独立自动保存于当前浏览器 `lifeatlas-modules-v1`。首次均开启，保留已有投资入口并让新板块可见；旧皮肤/粒子偏好不迁移、不覆盖。明确关闭值在刷新后保留。存储失败会提示本次有效、未能保存。

关闭仅隐藏导航，不删除记录或配置。关闭后手动打开 #investment 或 #life 会回到设置，可以重新开启；跨标签切换也更新可见入口，当前停在被关闭的板块时返回设置。跨标签变化不重绘其它模块，避免丢失成长草稿。模块设置不是账户级权限或数据隔离措施，也不是跨设备同步。

核心模块保持可见。显示数量为5–7项；手机5项时一排，6项时3列，7项时4列，较宽屏幕按实际可见数量排列。默认隐藏的链接不占布局且不能键盘聚焦。外观控制仍只在设置页。

## 人生丰富度

该句作为产品理念原样保留，当前仅建设阅读框架：兴趣与好奇、创作与表达、体验与探索、连接与共创。没有活动推荐、任务生成、生活记录保存或自动评分。

建议后续的体验路径：发现一件小事 → 尝试或创作 → 记录感受 → 选择分享/合作 → 回看是否愿意继续。提供独处和休息空间；不要求社交次数、不用连续打卡衡量生活。创作可包含做饭、整理与日常表达；连接强调自愿、边界和合作。与个人成长形成互补：成长侧重理解处境，这里侧重行动与生活体验，用户决定是否互相引用记录。
