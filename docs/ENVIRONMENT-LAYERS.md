# 个人成长 / 环境感知：五层结构

2026-10-29 的用户补充将环境改为由近到远的层次，继续保留“环境分析与成长”和“帮我看清局面”两个入口。模块位于“今日”之后、“邮箱整理”之前。

| 层次 | 看什么 | 与个人的联系 |
| --- | --- | --- |
| 个人 | 年龄阶段、特点、特长、职业、专业、行业、健康休息、经济与信息条件 | 自己的需要、已有能力、承受能力、可支配资源 |
| 家庭 | 父母的知识经验与做法、沟通、共同生活、责任和支持 | 对自己的真实支持、压力、依赖关系与边界 |
| 身边社会 | 学校老师、职场同事与管理、邻里同伴和亲密关系 | 规则、反馈、日常机会、具体冲突与求助渠道 |
| 地域与制度 | 区县、省市、自然环境与服务、区域经济、文化政策、地方治理与重要经济主体 | 资格、通勤、岗位、成本、资源集中与办事体验 |
| 宏观与外部环境 | 总体经济、就业价格、行业与专业传导、地缘关系、供应链和跨境变化 | 影响是否实际到达自己的收入、学习、生活与安全 |

地域可以记录华北、长三角、珠三角等跨区域联系。治理可以记录主要负责人在相应任职时期的公开施政重点、决策、承诺、政府服务与反馈。地方影响力可以记录主要企业、雇主与资源集中情况；涉及胁迫、违法或黑恶势力的线索，区分亲历、传闻、公开报道和司法材料，保留来源，不据传闻认定个人或组织。

## 由信息形成判断

档案的五层之下有“把大环境与自己连起来”：外部变化 → 区域或行业 → 组织或家庭 → 自己。每一环注明事实与假设，再记录支持、限制、来源和待核实信息。职业、专业与行业分别保存，便于观察职业位置与变化。

辅助分析新增地方治理与区域环境、宏观经济与行业影响、地缘及外部风险三个方向。相关领域可展开四项补充：观察到的变化、个人影响路径、证据与不确定性、下一次回看的信号。输入缺失时先追问，不补造事实。

四种选择仍保留首选、备选、折中或协商、暂时避让或暂缓。宏观情境的方案关注核实、个人暴露、基本资源、替代与可撤回准备；有明确伤害或威胁时，安全与可靠支持优先。儿童不被要求独自承担家庭财务或外部风险。

经济变化不会自动触发统一储蓄金额、买卖或投资指令。可以先梳理收入稳定性、必要支出、既有义务、可用资源和意外支出准备，再根据实际处境决定。地缘风险不会因居住在台湾或其他地区就被判定成立，也不会生成冲突概率、必然事件或仓促迁移的结论。

## 当前能力与依据

当前仍是有界的规则辅助分析，未接入大模型、实时新闻、政策数据库、领导人资料库、地方势力识别或宏观预测服务。用户填写的信息及链接不会被自动抓取或核实。它帮助整理与检查结构，不声称精确测量个人位置或完整理解复杂世界。

原有框架见 [两个入口的初版说明](ENVIRONMENT-SUPPORT.md)。本轮另参考 [CFPB 的现金流与应急储备说明](https://www.consumerfinance.gov/an-essential-guide-to-building-an-emergency-fund/) 和 [UNDRR 对事件、暴露、脆弱性与能力的区分](https://www.undrr.org/terminology/disaster-risk)。借用其思考角度，具体产品规则不属于机构量表、认证结论或经验证的预测模型。

## 保存与兼容

环境字段继续存于既有 JSON，新增的职业、专业、行业和地域宏观资料沿用每项长度校验、账户隔离、显式快照和版本历史，无新增数据库迁移。旧环境缺少的新字段留空，不被改写或推断。

新分析标记 `environment-guide-v2`，保存原始输入、传导路径、依据、观察信号、当时报告与选择。原有 v1 分析继续可读，保留当时版本，不套用后来的规则重算。查询和导出包含新增资料。

## 界面与验证

延续两套皮肤、湖景和粒子，强化标题、五层概览及深浅分区的两个入口。五层表单按需展开；宏观补充也可折叠。手机导航将较长名称分成两行，主题列表可横向浏览，正文与分析采用清晰的阅读层级。
