# LifeAtlas × 知识宇宙

## 融合方式

知识宇宙成为原 LifeAtlas 的独立主模块，路由为 `#knowledge`。原有今日、个人成长、邮箱、任务记录、可选投资及人生丰富度均保留，原API与数据库结构不变。

六个独立星系：股市、心理学、哲学、宇宙天文学、数学、物理。包含113个数据节点、112条包含关系、106条概念联系、8条路线，最深5层。使用本地Three.js运行旋转、缩放、逐层进入和跨系跳转。

3D运行时作为同源的独立模块装载，保留本地笔记和备份格式，不把内部DOM混入生活应用。嵌入模式隐藏重复品牌和侧栏，提供紧凑星系、路线、收藏、导入导出工具栏。

投资提供股市/量化/缠论/利弗莫尔入口，个人成长提供心理学入口。`#knowledge:节点id`可定位知识；内部记录不自动改写人生观察或投资判断。

## 动态星空

`src/cosmic-background.ts`在本机生成星云纹理、层次星野、缓慢漂移和星光闪烁。全应用共用一片背景，包括导航和知识模块的透明3D场景；没有外部图片、视频、CDN或付费API。

动态控制只在“偏好设置 → 外观与动态”显示。保留原有两套皮肤和偏好键 `lifeatlas-appearance-v1`，关闭动态后保留静态星空。输入、页面后台、系统减少动态时暂停；前台背景上限桌面24fps、窄屏20fps，位图限制约170万像素。3D本身上限约30fps。

## 数据与权限

知识使用独立浏览器键 `atlas-knowledge-universe-v1`；个人成长继续使用原数据库，邮箱连接继续使用原服务端配置。融合不读取或上传本机其他浏览器的记录，也不自动连接真实Gmail或开通行情。

原知识宇宙通过file://打开时，与本应用的HTTP地址不共享存储。迁移时，在原版导出JSON，再到融合版知识模块导入。V1/V2备份均可用。清理浏览器数据前应导出。

复用源文件位于 `public/knowledge-universe/`，Three.js和字体许可随文件保存。共享星空从同一份TypeScript打包，使用 `node scripts/build-cosmic-background.mjs`同步模块内发行文件。更新业务不需要付费服务。

## 本地运行

按仓库原运行方法 `npm ci`、`npm run dev`，或双击“启动融合版.cmd”。正式个人记录与QA测试数据库隔离；源码提交与ZIP不包含任何个人内容、数据库、邮箱、密钥或依赖缓存。
