# 环境感知（2026-10-25）

个人成长需要同时看见自己的选择，以及家庭、组织、地域、政策和文化提供的条件。环境资料与具体经历、理解和尝试一起留存，帮助回看“我变了什么、周围又变了什么”。

## 本轮实现

在个人成长主题中点击“环境感知 · 维护主题环境”，记录从某个日期起适用的环境。可以先填写最重要的一项，随后补充。

| 维度 | 记录内容 |
| --- | --- |
| 家庭与共同生活 | 家庭角色、照护责任、沟通与支持 |
| 同事、工作与组织 | 岗位、同事、公司规则；也适用于学校或其他组织 |
| 地域与生活条件 | 县城或城市、居住、通勤、公共服务和生活成本 |
| 政策与社会环境 | 相关政策、行业与就业条件，注明适用地区、有效期和核实情况 |
| 风俗、文化与人情 | 实际遇到的风俗、人情往来、价值期待，保留具体情境 |

另外可以记录支持资源、当前限制，以及依据、来源和待核实之处。环境描述由本人维护，是当下的观察；系统不把转述或待核实政策当成已验证事实。

记录经历时，展开“这次经历的环境”，主动选择保留环境描述，也可点击“使用主题环境作为起点”再修正。填写“这些条件如何影响这次选择”，区分能够协商的空间与暂时需要适应的条件。

## 时间与版本

- 主题环境是当前可复用的描述；每次更新保留主题版本。
- 经历里的环境是该次保存的独立副本。后来搬家、换团队或家庭分工改变，不会改写过去的经历。
- 环境起始日期不能晚于经历日期。补记过去时需要按当时情况修正，旧记录不会自动套入今天的环境。
- 经历中的环境可以补充、修正或取消附上；原有文字仍在修改历史中。旧客户端未提交环境字段时保留原值。
- 前后对照和变化过程都可展开当时环境；阶段回顾和反馈来源保留环境摘录（每项最多 300 字符、影响最多 500 字符），完整原文可从版本历史查看。
- 关键词检索包含环境和影响；主题 JSON 导出包含当前主题环境、经历环境与修改历史。

## 保存与边界

本轮首先在各成长主题中使用，尚无跨主题共享的全局环境档案。每项环境说明最多 1500 字符，环境影响最多 2000 字符；来源可记录文字与链接，链接不会被自动抓取。

资料保存在当前生活空间数据库，沿用账户隔离与手动保存。本轮没有自动定位、抓取公司或家庭资料、实时政策同步、风俗推断或 AI 分析，也没有接入第三方感知服务。隐私、云端存储、导出和历史保留规则与既有成长记录相同。

## 工程与验证

新增 `growth_topics.environment_profile`，由迁移 `0003_polite_cloak.sql` 以 `{}` 为常量默认值添加；经历环境存于既有 `context`。迁移不改写旧正文，既有迁移保持不变。

45 项自动测试通过，其中本轮 6 项覆盖版本与账户隔离、显式副本、日期和长度校验、修改与取消后的历史、来源摘录、跨页环境检索。类型检查与生产构建通过。

本地浏览器使用“演示｜环境与选择（虚构）”独立主题，验证环境维护、显式带入、输入保留、日期错误恢复、环境更新后的跨年对照。所有演示文字均明确标记虚构，不随源码上传或部署。

收尾评审：沿用两套皮肤与粒子；检查了桌面环境对照和约 390px 的手机表单。修正比较列继承的大字号卡片样式与多字段间距，使环境保持普通阅读层级。该检查不代表所有设备或所有可访问性状态的完整认证。
