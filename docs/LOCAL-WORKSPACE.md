# LifeAtlas 本地工作空间 · 0.2

## 这次可以实际使用的功能

- **今日**：显示自己的待办和最近投资、生活记录，不填充演示邮件。成长经历从个人成长进入回看。
- **个人成长 / 环境感知**：原有主题、经历、五层环境、历史版本和规则报告继续使用；可把当前页面显示内容带入 AI 分析预览。已有示例主题不会被升级自动删除，用户可以收起它们。
- **投资研究**：本地研究日志、分类、日期、修改、删除、JSON 导出和 AI 分析入口；没有券商接入、实时价格或自动交易。
- **人生丰富度**：兴趣、创作、体验、连接四类真实生活记录，保留自己的日期与文字。
- **任务记录**：本地待办、完成与重新打开、编辑、删除、导出，以及最近操作记录。
- **AI 分析**：自己的兼容 API 或本机模型服务，明确预览问题和引用，勾选确认后请求，结果、输入、模型、地址与时间保存到 SQLite。界面显示最近 100 条，较早分析仍在数据库与备份中。
- **邮箱**：Gmail、163、QQ 各配置一个账号，TLS IMAP 只读同步最近 50 封收件箱标题。手动打开邮件时缓存文本正文，已缓存正文可离线阅读。列表显示最近 200 条缓存；不发送、删除、归档或标记已读。
- **知识宇宙**：七个内置星系加最多 24 个自建星云；支持重命名和删除自建星云，内置星系保留。可以上传知识库，组成独立星云或并入已有星云；框架和片段以真实层级进入三维图谱。

## AI 怎么接入

到「偏好设置 → 我的 AI 服务」填写基础地址、模型名与 API Key。例如，已经在本机安装并准备好模型的 Ollama 可以使用 `http://localhost:11434/v1`；LM Studio 等服务请使用其实际地址与模型标识。远程服务必须使用 HTTPS；HTTP 只允许 localhost、127.0.0.1 或 ::1。仅支持兼容 `/chat/completions` 的文本接口，暂不支持 Responses、图片输入或工具执行。

保存不发起模型调用。「测试连接」只访问 `/models`；部分厂商不提供该接口，仍可尝试实际分析。更换服务地址且密钥留空时，不会把旧服务的密钥带给新地址。

在 AI 分析页输入问题，选择知识库，点击「检索并预览引用」。关键词检索在本机完成，最多返回八个约 2,800 字的片段；并非语义向量检索，也不保证覆盖全部资料。可以修改或清空引用。只有点击「开始分析并保存」才会发送屏幕上列出的问题和引用；程序没有让模型自行读取磁盘、邮箱或执行操作的工具。邮件和成长内容须先由用户选择带入预览。

未配置 AI 时，记录、知识库、图谱与原有规则辅助功能仍能使用。本机模型需由用户预先准备；程序不自动下载大型模型，也不自动使用付费 API。远程服务费用由用户自己的服务商计算，本机解析、绘图和模型推理会消耗本机算力。

## 知识库怎么导入

打开「知识宇宙 → 星云与知识库」。可先创建星云，也可上传时新建。支持 UTF-8 TXT、Markdown、JSON、CSV，带可提取文字的 PDF，以及 DOCX。扫描版 PDF 需先 OCR；旧 `.doc`、图片和 ZIP 知识库暂不支持。JSON 按原文保留，不猜测其字段或自动建立语义关系；宇宙备份 JSON 继续使用原有「导入备份」。

原文件在点击「提取并预览」后存入本地数据库。确认后，以文件框架和不超过 7,800 字的原文片段组成星云节点。解析不连接外部 AI，也不把文件发送到网络。最多 500 个自建知识节点；单文件最大 20MB，提取文字最多 150 万字，本地文件与文本合计最多 50MB、200 个文件。宇宙索引接近 3.8MB 时会提示整理；更大的原文仍保留在文件库。

「偏好设置 → 我的知识库文件」可下载原文件或删除原文件。删除文件不会删除已写入星云的摘录，删除星云也不会删除文件库原件。备份中含原件和摘录。自建星云和片段也兼容宇宙 JSON 导出/导入。

独立静态知识宇宙仍可用 `file://` 打开，支持自建星云和 UTF-8 文本导入；PDF/DOCX 解析、原文件保存和 AI/邮箱功能需要完整本地程序。

## 邮箱怎么连接

「偏好设置 → 邮箱连接」选择 Gmail、163 或 QQ，填写完整地址和**客户端授权码 / 应用专用密码**，不用网页登录密码。163 与 QQ 需先到邮箱设置开启 IMAP 并生成授权码。Gmail 通常需两步验证后的应用专用密码；组织策略、高级保护等可能禁止这种方式。当前新增本地入口采用应用密码 IMAP，没有新增 Google OAuth 向导；源码原有只读 OAuth 服务继续保留。

连接目标固定为 `imap.gmail.com:993`、`imap.163.com:993`、`imap.qq.com:993`，开启 TLS 和证书验证。163 连接发送客户端 ID。保存配置不会开始同步，到邮箱页点击「同步最近50封」后才联网。单封正文读取上限 3MB，文本缓存最多保留前十万字；不显示远程图片或执行邮件 HTML。完整缓存进入个人数据库和备份。手动同步不修改邮箱原始邮件。

协议已使用本机模拟服务验证，尚未替用户登录真实账号；真实连通性取决于用户的网络、授权码与账号策略。连接失败不会被显示为成功，缓存可以继续查看。

## 数据与连接密钥

日志、任务、知识库、成长历史、邮件缓存及 AI 分析存入 `LifeAtlas本地资料/lifeatlas.sqlite`。完整资料备份包含这些内容，因此也包含用户选择保留的邮件和 AI 输入，请妥善保存。

API Key 和邮箱授权码在资料目录另存为 AES-256-GCM 加密的 `connection-vault.enc`，密钥为同机的 `connection-vault.key`。接口只返回已配置状态，不把密钥回传到浏览器；不是端到端加密或抵御本机账户入侵的承诺。两个文件都不要上传公开仓库。完整资料备份不包含连接密钥，换电脑或重装后需重新填写；若手动备份整个资料目录，应把它当作敏感文件保管。

升级前生成备份，停止本机服务，只替换程序文件并保留资料目录。进行 AI 分析、解析或同步时不允许恢复数据库，避免操作写入被替换的资料。旧完整备份可继续恢复；首次使用新增功能时会创建缺少的数据表。

## 皮肤与设计约定

用户在 2026-11-03 明确将此前两套深色皮肤改为 **深空 · 暗色** 与 **晴空 · 亮色**。保留 `island` / `observatory` 存储标识以兼容旧偏好；这两个名称的旧视觉承诺由本轮用户指令取代。

暗色保留低亮度星空。亮色采用本机程序绘制的蓝天白云、浅色导航与阅读面；知识宇宙的三维视口保持深空以保证星云可见，周围控件、阅读和文件管理随皮肤切换。设置只更改文档属性，不重建当前输入；动态背景可关闭，输入、后台与系统减少动态时暂停。

界面以任务为中心：记录列表加连续编辑区，AI 问题—引用—确认—结果，邮件列表加文本阅读区。延续 LifeAtlas 字标与简洁控件，避免用演示内容填充真实模块。桌面 1450px 和手机 390px 为本轮检查尺寸。没有新调用付费图像服务或云渲染。
