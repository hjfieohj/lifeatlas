# 主体、影响与行动：融合分析 v3

2026-10-31。用户确认在原有五层环境和两个入口之上，融合个人处境、周围主体的特点、相互作用、行动空间与认识变化。当前是有明确边界的规则辅助整理，未接入大模型，没有 AI 调用、来源抓取或实时验证。

## 使用路径

进入「个人成长 / 环境感知」，选一个主题，再点「分析困扰与选择」。先写一件具体的事、已经受到的影响、希望改变什么，以及自主空间和安全情况。可以直接整理，也可以补充关键主体。

每次最多 6 个主体。主体可以是人、组织或制度／环境条件，归于个人、家庭、身边社会、地域与制度、宏观与外部环境。无需真实姓名。每个主体分别记录：

- 具体事例或规则：判断的起点，必填。
- 与自己的关系、决定权与资源：避免脱离现实依赖谈改变。
- 自己理解的特点与行为选项：是用户标注，系统未独立核实。
- 已经发生的影响、可能发生的影响：两者分别保存和展示。
- 来源、时间和不确定性：亲历、转述、公开资料和未知分别标注。

至少有两个主体时，可以记录最多 6 条联系，说明它们如何叠加要求、提供缓冲或形成冲突，以及依据、对自己的影响和核实情况。程序不会仅根据主体名称或层次自动补造关系。

「带入主题环境摘录」保留已有草稿，将个人条件带入尚未填写的项目，把另外四层环境转为注明起始日期的摘录。摘录需要进一步拆分和核实，不能视为已确认的具体人物画像。重复带入不会覆盖原摘录；达到上限时说明未带入数量。晚于当前经历日期的档案不能带入。

## 四部分结果

1. **我和周围的环境，分别是什么样的？** 保留自己的特点、阶段、希望、支持与限制，概括本次涉及的主体。
2. **这些特点相遇，会形成怎样的处境？** 综合线索后，逐个展开「观察依据 → 特点 → 与我的关系 → 对我的影响 → 可行回应」。用户理解、用户标注、关键词线索分别标明；联系仍保留为观察或假设。
3. **在这个处境中，我有哪些行动空间？** 结合依赖程度、资源与限制，保留首选、备选、协商妥协、暂时避让四类有条件方案，说明适用条件、行动、代价与停止条件。安全担忧和伤害／威胁线索优先，不把独自对质或忍受伤害作为要求。
4. **行动和变化发生后，我该怎样更新认识？** 记录实际行动与结果、个人／主体／外部条件的变化、得到支持或需要修正的判断，以及下次回看的信号。

主体描述使用与原分析一致的有限关键词线索；未识别到线索不能证明没有风险。支持与压力可以共存。不诊断人格、不按地域或学历给人分级、不自动认定违法行为，也不提供统一的投资或政治预测结论。

## 保存与回看

分析预览不等于保存。修改任何分析输入会使旧预览失效；新增、移除主体或联系后需要重新分析。保存时服务器重新校验输入并生成报告，不采信客户端伪造的分析内容。服务器保存原始主体、联系、输入、报告版本和所选行动；没有新增数据库迁移。

在「回应这次尝试」中，可以展开当时分析，填写实际结果及认识变化。反馈关联原尝试的固定版本；阶段总结继续使用既有的选材和引用机制。新的认识通过新记录继续，不能用新版规则覆写旧分析。v1、v2 原报告继续按当时版本读取，原记录编辑和导出也保留分析原文。关键字检索包含主体和联系输入。

每项主体资料、联系和总输入都有长度上限；数据仍按生活空间用户隔离保存于服务端，不是端到端加密。个人记录、数据库、导出、密钥与运行时配置不进入公开 GitHub。界面仍使用已选定的「生活阅览室」布局和两套皮肤；新增资料按可展开的连续阅读条目呈现。
