# 国际投资板块：初始规划

2026-10-31 用户要求：先建立独立投资主模块，聚焦国际市场的基金、债券、股票，内容稍后添加。

本轮仅新增导航和静态规划页，不保存投资数据，不接行情、券商、AI研究或交易，不展示虚构持仓、价格、业绩或推荐。

## 内容分层

- 市场观察：美国、欧洲、亚太、新兴市场；市场概览、利率/汇率、事件日历。上市地、实际资产敞口、币种应分开。
- 基金与ETF：投资目标、底层持仓、费用、跟踪误差、分红/累积方式、注册地及资料来源。基金/ETF是持有资产的载体，可包含股票或债券，不能和底层资产重复统计配置。
- 债券：发行人、主权/公司类别、计价币种、期限、票息、价格、到期收益率、信用等级及日期、流动性；债券基金与直接持债分别展示。评级只表示特定机构在特定时点的意见。
- 股票：公司与行业、财务、估值、公告、上市交易所和证券标识；分清同一公司不同上市地/股份类别。
- 自选与研究：加入关注、按资产/市场筛选、来源链接、研究依据、反例、待验证条件，暂不设计自动买卖评分。
- 组合与复盘：先手工记录或导入，展示资产/行业/地区/币种分布、费用与收益口径，保留决策、实际结果与认识变化。现金流和汇率影响分开，未实现/已实现收益分开。

## 实现顺序

1. 当前：六个主模块中的独立入口 + 明确的待完善页面。
2. 下一步优先：确认个人使用范围、常用市场/工具、基础计价币种、数据来源与授权；实现自选与来源明确的研究资料。
3. 然后：有时间戳和延迟说明的行情与资料比较，明确市场交易时段和货币单位，不把价格当实时。
4. 再做：个人记录、组合分析、决策复盘和可选提醒。跨境准入、税务与账户所在地相关信息应注明适用条件及日期；数据接入、账户连接和交易另行决定。

## 设计约束

沿用生活阅览室、两套皮肤、现有Uiverse组件与粒子。静态规划条目保持阅读语义，不放不可用的假按钮。移动端主导航六项；新增路由支持直接打开与刷新，既有离开成长草稿确认保留。外观控制仍仅在偏好设置内。

信息结构参考 Investor.gov 的 [Investment Products](https://www.investor.gov/introduction-investing/investing-basics/investment-products) 与 [International Investing](https://www.investor.gov/introduction-investing/investing-basics/investment-products/international-investing)。这些资料用于组织产品需求，不构成对用户的配置或买卖建议。
