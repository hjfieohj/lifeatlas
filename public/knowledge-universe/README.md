# LifeAtlas 知识宇宙模块

这是融合版的自包含知识运行资源，由主应用的 `src/knowledge.ts` 挂载。完整融合说明见仓库根目录 `docs/KNOWLEDGE-UNIVERSE.md`；日常使用建议从主应用 `#knowledge` 进入。

## 独立复用

保留整个目录，可直接打开index.html或放在静态HTTP服务下。字体、Three.js、自由轨迹球控制、数据和代码生成的星空均在本地，无需CDN或付费API。`?embedded=1`供同源LifeAtlas嵌入，隐藏重复品牌/侧栏，并通过经过来源校验的消息报告输入状态；独立使用不要加这个参数。

六个独立领域：股市、心理学、哲学、天文学、数学、物理。包含113个节点、112条包含关系、106条语义关系、8条学习路线，最深5层。左键拖动自由翻转，松手保留惯性；滚轮或双指缩放，右键平移。点击亮星或标签逐层进入，顶部路径返回，沿跨系入口跳转。总览收起阅读面板，点击节点恢复阅读，也可用面板按钮切换。

收藏、已读、自建框架、笔记保存在当前浏览器，建议导出JSON。不同地址和浏览器不共享记录；旧file://版可导出后在融合版导入，支持V1/V2备份。父级用parent表示，循环层级被拒绝，删除自建框架会把下级移到上一层。

`knowledge.json`是起始数据，编辑后运行 `node sync-data.cjs`校验并同步knowledge.js；无需重建Three.js。新增领域应在domains中定义，并添加父级为universe的根节点。运行时和源码边界、许可见THIRD_PARTY_NOTICES.md与vendor目录。

`nebula-field.js`生成有XYZ深度的气体、星尘、亮星和暗尘体积；概念联系呈现为星尘光带。星云是知识结构示意，不是天文比例模拟。缓慢自转可单独关闭，融合模式同时遵守全局动态偏好；输入、页面后台和减少动态时暂停自主运动。外部参考链接需要联网；金融内容不接实时行情或自动产生投资信号。原知识代码和摘要为MIT，Three.js为MIT，SpaceGrotesk字体为OFL。

文字贴在对应的星云核心并跟随其投影，不绘制标签引线，也不把标签推到远处。旋转时重叠或离开可用视野的次要标签会暂时隐藏；完整知识始终可通过搜索和层级目录进入。
