# 知识宇宙 ATLAS 2.0 · 3D分层版

可离线使用、自行扩展的3D知识宇宙。六大独立星系：**股市、心理学、哲学、宇宙天文学、数学、物理**。数学与物理已经分开。

初始数据：113个节点（含宇宙根、6个领域、子框架与具体知识），112条包含关系、106条概念关系、8条学习路线；从宇宙根出发最深5层。

## 打开

单文件版：双击交付的“知识宇宙.html”或“知识宇宙-3D版.html”。字体、3D引擎、数据均已内嵌，无需安装、账号或网络。

多文件版：解压完整工程，双击index.html，保留旁边全部脚本、样式和vendor文件夹。

固定本地地址：在本机已有Node.js时，双击“启动本地服务.cmd”，访问 http://127.0.0.1:8765 。仅监听本机；关闭命令窗口或按Ctrl+C停止。

3D需要支持WebGL2的浏览器。无法启动WebGL时，会显示说明并切换到层级目录，知识阅读与笔记仍可使用。file://的存储规则由浏览器决定；固定HTTP地址适合长期使用。

## 逐层探索

- 左键拖动旋转，滚轮缩放，右键拖动平移；触屏使用单指旋转、双指缩放/平移。
- 总览展示六大领域及主要框架。点击有下级的星球进入系统，显示下一级框架与知识。点击具体知识进行阅读。
- 顶部面包屑说明当前层级；“上一层”返回父系统，“全部星系”回到总览。
- 实线轨道表示包含关系；虚线表示概念联系。总览会把部分深层联系汇总到可见框架。选择具体知识后，跨系关联会显示为可点击的跃迁入口，点击进入目标所属系统。关系理由在阅读面板中说明。
- “跨系联系”可开关关联显示；“自动环绕”让镜头缓慢转动，默认关闭，减少运动偏好下不自动转动。
- “层级目录”保留完整可展开的包含树。搜索支持中文、英文条目名和正文关键词；/聚焦搜索，上下键选择，回车进入。

路径示例：

- 知识宇宙 → 股市 → 量化交易 → 策略研究 → 回测。
- 知识宇宙 → 股市 → 缠论 → 走势结构 → 分型与笔。
- 知识宇宙 → 宇宙天文学 → 银河系与星系 → 太阳系 → 地球 → 月球。
- 知识宇宙 → 数学 → 概率与统计 → 概率 → 贝叶斯定理。
- 知识宇宙 → 物理 → 现代物理 → 量子力学 → 不确定性原理。

空间、大小、表面纹理与轨道是知识导航示意，不是按真实天体比例和星历参数构建的模拟器。包含树也是一种学习组织方案，知识还可以通过语义关系连接其他系统。

## 长成自己的宇宙

“添加知识”支持指定所属星系与父级框架，并选择跨系联系。自建知识还可以继续包含下级。删除自建框架时，直接下级移到上一层，不会一起删除；系统会拒绝循环父子关系。

收藏、已读和笔记存在当前浏览器，请定期导出JSON备份。导入合并数据，相同id的自建知识与笔记以导入版本为准。V1备份兼容，没有父级的旧自建节点默认放在所属领域下；V2导出保留父级。

不同浏览器、file与HTTP、不同端口的记录互不共享，迁移时使用备份。清理浏览器数据或隐私模式可能使记录消失。

限制：最多500个自建节点、4MB备份、单条笔记20,000字、自建层级最多32层，浏览器存储容量也可能先达到上限。保存失败时会提示导出。本版本面向个人小型知识库，未对数千个同时展开节点作性能承诺。

## 修改与复用

无构建步骤的静态网页，可复制到其他电脑或静态站点。

- index.html、style.css：页面结构和响应式布局。
- universe3d.js：三维层级布局、行星、镜头、交互、跨系入口和标签避让。
- app.js：导航、阅读、个人记录、自建框架与备份。
- knowledge.json：数据源，parent表示父级，links.kind区分hierarchy包含与relation语义联系。
- knowledge.js：浏览器直接读取的数据。
- vendor/three-runtime.min.js：本地Three.js与OrbitControls。
- sync-data.cjs：编辑JSON后，运行node sync-data.cjs校验、计算深度并同步脚本。
- build-standalone.cjs：运行node build-standalone.cjs生成单文件HTML。
- server.cjs：可选的零依赖本机HTTP服务。

新增领域时，在domains定义名称、颜色，再添加父级为universe的领域根。引擎自动布置位置，无需手写领域坐标。保持id唯一、父级可达、包含树无环。

## 来源与成本

本地文字为原创中文入门摘要。Wikipedia、NASA、Stanford Encyclopedia of Philosophy、MIT OCW、OpenStax、Investor.gov、Qlib和CZSC为联网延伸阅读，不是全文镜像，也未声称链接支持节点的全部表述。

股市包含量化、缠论、利弗莫尔及各自定义与证据边界，不接实时行情，不生成自动投资信号。概念连线有理由，不表示连线本身证明因果或等价。

不调用付费API、云渲染、远程字体或CDN。制作使用当前对话已有模型额度和本机CPU进行代码、打包及无头浏览器检查，没有额外付费API。

3D会使用本机显卡/CPU与内存。默认不自动环绕，前台上限约30帧/秒，后台或目录模式暂停场景绘制。代码与原创摘要为MIT；Three.js为MIT、Space Grotesk为OFL，许可随包附带。
