# LifeAtlas knowledge integration

Mode: Operate/Experience with preserved reading and personal-data flows.

## Direction contract

THESIS: One personal atlas joins everyday reflection with a navigable3D knowledge universe; the shared deep sky carries the total project.
OWN-WORLD: Preserve LifeAtlas wordmark, rails, native controls and two appearance choices; translate surfaces to ink navy, moonlight text and opaque reading planes over locally generated nebulae and twinkling stars. Knowledge keeps six domain accents and actual sphere meshes.
STORY: Move between daily life, growth, investments and knowledge; enter a framework, read or note a concept, return to real reflection without automatic claims about the user.
FIRST VIEWPORT: One outer LifeAtlas navigation. The knowledge module has a compact search/domain toolbar instead of a second brand/sidebar; its transparent 3D world continues the same background. Other modules retain structured reading surfaces.
FORM: User-pinned integration and dynamic cosmic background. No new identity tournament; the earlier white-paper/flow-landscape descriptions are superseded only for background and cosmic colors. Existing data and permission boundaries are retained.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

Functional evidence uses an isolated QA copy/database, not the user's local records. Runtime background is code-generated; no sourced/generative bitmap is shipped.
