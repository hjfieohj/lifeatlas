# Three selectable life-space skins
Mode: Operate + Read. This is the actual app, not a static concept preview.

## Direction contract
THESIS: A quiet personal workspace has an appearance the owner can choose without interrupting the reflection or administrative task in progress.
OWN-WORLD: User approved three live alternatives and selected Daylight before asking to keep all as skins. Daylight: cool white/cyan, spacious opaque reading surfaces. Orbit: navy/cyan, dated timeline track. Habitat: graphite/sand, horizontal desktop shell. Shared existing self-hosted AtlasSerif titles, Chinese system UI text and authored outline icons. No new illustration assets.
STORY: Select a skin in the shared topbar or appearance settings; keep the live input; refresh to return to that preference. Observe life and changing interpretations in the real growth module.
FIRST VIEWPORT: Five usable navigation destinations, current location, visible skin selector and independent particle checkbox. Default is Daylight. Settings exposes the same synchronized choices with persistence and motion explanations.
FORM: Code-led adaptation of the three live previews, converted to permanent semantic CSS palettes. Native select and checkbox controls, no carousel or preview overlay. Signature interaction: instantaneous skin switch preserves unsaved form values; background particles remain peripheral and pause while writing.
FINISH: Review the actual implemented shared shell and settings in all skins, source-check continuity of functional modules. No AI, psychological scores, streaks, journal fabrication or new data sharing. No live preview scripts or tokens ship.
